# Git Resources

## Knowledge

- [Book: _Pro Git_ (2nd Edition) by Scott Chacon & Ben Straub](https://git-scm.com/book/en/v2)
  The official, definitive book on Git. Use for: internal object database architecture, plumbing commands, and branching models.
- [Visual Guide: "Git from the Inside Out" by Mary Rose Cook](https://maryrosecook.com/blog/post/git-from-the-inside-out)
  In-depth mental model of Git as a content-addressed graph. Use for: visualizing blobs, trees, commits, and refs.
- [Tutorial: "Atlassian Git Guides"](https://www.atlassian.com/git/tutorials)
  Practical, clear workflows. Use for: rebasing vs merging, undoing changes, and remote workflows.
- [Reference: Official Git Documentation & Man Pages](https://git-scm.com/docs)
  Canonical reference. Use for: exact CLI parameter semantics and edge-case behavior.

## Wisdom (Communities)

- [Stack Overflow [git] Tag](https://stackoverflow.com/questions/tagged/git)
  Highest-signal community archive for Git emergency recovery, detached HEAD fixes, and reflog recipes.
- [Git Official Mailing List & Discussions](https://github.com/git/git)
  Primary forum for Git architecture discussions and design decisions.
