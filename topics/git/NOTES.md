# Notes: Git Learning Workspace

Working scratchpad for capturing user preferences, pacing insights, and curriculum planning.

## Learner Profile & Preferences
- **Experience Level**: Beginner ("noob") wanting to build complete confidence from basic to advanced.
- **Tone & Style**: Plain and simple English. Start with "Why" (the real-world problem) and "How" (Git's conceptual solution).
- **Format Preference**: Animated visual concept demonstrations in interactive HTML lessons.
- **Primary Tool**: Terminal Command Line Interface (`git` CLI).

## Curated Curriculum Roadmap (From Basic to Advanced)
1. **Module 1: The First Principles (Why & How)**
   - *Lesson 0001 (Completed)*: Why We Need Git & The Snapshot Time Machine (Folder Chaos vs Git Snapshots).
   - *Lesson 0002 (Completed)*: The 3 Areas of Git: Working Directory, Staging Area, and Commit History.
   - *Lesson 0003 (Next)*: First Real Commit Cycle & Inspecting History with `git log` and `git diff`.

2. **Module 2: The Daily Workflow & Inspecting History**
   - *Lesson 0004*: Making atomic commits, writing great commit messages, and `git log`.
   - *Lesson 0005*: Seeing changes before committing: Mastering `git diff` and `.gitignore`.

3. **Module 3: Branching & Merging (Parallel Realities)**
   - *Lesson 0006*: What is a Branch? (It's just a lightweight movable pointer!).
   - *Lesson 0007*: Fast-Forward Merges vs Three-Way Merges.
   - *Lesson 0008*: Facing the Beast: Resolving Merge Conflicts step-by-step in the terminal.

4. **Module 4: Collaboration & Remote Repositories**
   - *Lesson 0009*: Remotes Demystified: `origin`, `git remote`, and `git clone`.
   - *Lesson 0010*: Syncing Work: `git fetch` vs `git pull` vs `git push`.

5. **Module 5: The Time Machine (Undoing Mistakes)**
   - *Lesson 0011*: Discarding uncommitted edits: `git restore`.
   - *Lesson 0012*: Undoing committed work safely: `git revert` vs `git reset` (soft, mixed, hard).

6. **Module 6: Intermediate & Advanced Workflows**
   - *Lesson 0013*: Shelving temporary work: `git stash`.
   - *Lesson 0014*: Rebase vs Merge: Rewriting history cleanly.
   - *Lesson 0015*: Interactive Rebase: Squashing, rewording, and reordering commits.
   - *Lesson 0016*: Cherry-picking commits across branches.

7. **Module 7: Deep Git Internals & Lifesaver Recovery**
   - *Lesson 0017*: Under the Hood: Blobs, Trees, Commits, and the Object Store (`.git/objects`).
   - *Lesson 0018*: The Safety Net: `git reflog` and recovering deleted branches/commits.
