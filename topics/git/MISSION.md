# Mission: Git Mastery

## Why
Master Git to confidently version control codebases, navigate branches and merges without anxiety, resolve complex conflicts, and recover cleanly from mistakes using core Git internals.

## Success looks like
- Confidently navigate Git's three trees: Working Tree, Index (Staging), and Commit History.
- Understand Git's underlying content-addressable object store (blobs, trees, commits, annotated tags).
- Manage branching, merging (fast-forward vs 3-way), rebasing, and squash merges smoothly.
- Resolve tricky merge and rebase conflicts with confidence.
- Master recovery tools: `git reflog`, `git reset` (soft/mixed/hard), `git restore`, `git revert`, and detached HEAD states.
- Apply high-signal commit hygiene, cherry-picking, and remote synchronization workflows.

## Constraints
- Focus on foundational mental models and practical muscle memory.
- Interactive, self-contained HTML lessons with runnable simulation and review checks.

## Out of scope
- Platform-specific CI/CD automation (e.g. GitHub Actions syntax) beyond standard remote push/pull/PR interactions.
