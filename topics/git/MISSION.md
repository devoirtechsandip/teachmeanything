# Mission: Git Mastery (From Basics to Advanced CLI)

## Why
Master Git from the ground up to confidently version control codebases, understand how code history is preserved, collaborate without fear, and operate the Git command-line interface (CLI) with deep mental models and fluency.

## Learner Profile & Persona
- **Starting Level**: Complete beginner ("noob") needing plain, simple English explanations and clear, intuitive analogies before technical mechanics.
- **Learning Style**: Visual and interactive, grounded in animations to clarify abstract concepts (such as snapshots, references, staging, and branching).
- **Target Interface**: Pure Command Line Interface (CLI) muscle memory and terminal fluency.

## Success Looks Like
1. **The First Principles ("Why & How")**: Clearly understand why manual backups fail, how Git's snapshot model works, and why distributed version control transforms software development.
2. **The Three Trees**: Fluidly navigate the Working Directory, the Staging Area (Index), and the Commit History using commands like `git status`, `git add`, `git commit`, `git diff`.
3. **Branching & Merging Mastery**: Create and switch branches, understand fast-forward vs 3-way merges, and resolve merge conflicts calmly from the terminal.
4. **Remote Collaboration**: Push, pull, fetch, and coordinate with remote repositories (e.g. GitHub/GitLab) with clear mental tracking of local vs remote tracking branches.
5. **Time Travel & Undo Playbook**: Know precisely when and how to use `git restore`, `git reset` (soft, mixed, hard), `git revert`, and `git checkout`.
6. **Advanced Workflows & Internals**: Rebase cleanly (including interactive rebasing `git rebase -i`), stash work, cherry-pick commits, understand Git's internal object store (blobs, trees, commits), and recover "lost" work using `git reflog`.

## Constraints
- Plain, accessible English without unexplained jargon.
- Self-contained, beautiful interactive HTML lessons featuring runnable animations, interactive practice, and retrieval quizzes.
- Focus strictly on practical CLI command-line workflows.

## Out of Scope
- Vendor-specific CI/CD YAML configurations (GitHub Actions, GitLab CI) beyond standard remote push/pull/PR interactions.
