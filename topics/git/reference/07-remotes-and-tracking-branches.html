Remotes & Tracking Branches Cheat Sheet

Managing remote configurations, clone shortcuts, and branch upstreams.

Remote Configuration Commands

# View configured remote names and URLs
git remote -v

# Add a new remote alias
git remote add origin git@github.com:user/repo.git

# Clone repository with full history
git clone https://github.com/user/repo.git

# Push local branch and link upstream tracking (-u)
git push -u origin main

# Inspect upstream branch tracking status
git branch -vv
