Quick Reference Card #08 ⚡ Cheat Sheet

Syncing: Fetch, Pull & Push Reference

Synchronizing local changes with remote git repositories safely.

Sync Command Cheat Sheet

# Download all remote updates without touching working tree (100% safe)
git fetch origin

# Fetch and merge into current checked-out branch
git pull origin main

# Pull with rebase instead of merge (cleaner linear history)
git pull --rebase origin main

# Push local commits to remote tracking branch
git push origin main

# Safely push rewritten history without stomping teammate commits
git push --force-with-lease origin feat/my-branch
