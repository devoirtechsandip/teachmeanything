History, Diffs & Hygiene Quick Reference

Key commands for diffing, history formatting, and repository cleanliness.

Diff Commands Matrix

Command Left Side (From) Right Side (To) When to Use
git diff Staging Area (Index) Working Tree Review edits before git add
git diff --staged HEAD (Last Commit) Staging Area (Index) Final sanity check before git commit
git diff HEAD~1 HEAD Previous Commit Latest Commit Review changes introduced in most recent commit

Essential Log Formatting Flags

git log --oneline - Compact single-line summary with abbreviated SHA.
git log --graph --oneline --decorate --all - Visual ASCII branch tree across all branches.
git log -p -2 - Show full line-by-line diff for the last 2 commits.
git log --stat - Show files changed and lines added/deleted summary.
