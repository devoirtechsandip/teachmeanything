Git Object Store & Plumbing Reference

Cheat sheet for inspecting blobs, trees, commits, and cryptographic hashes in .git/objects/.

Plumbing Commands Reference

# Inspect object type (blob, tree, commit, tag)
git cat-file -t <SHA>

# Pretty-print raw object content
git cat-file -p <SHA>

# Compute SHA and write raw blob to .git/objects
git hash-object -w <filename>

# Inspect raw tree object listing without checking out
git ls-tree <tree-SHA-or-commit>

# Verify integrity of database objects
git fsck
