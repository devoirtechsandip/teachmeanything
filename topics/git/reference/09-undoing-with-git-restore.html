Uncommitted Edits & git restore Reference

Clean modern commands for unstaging and discarding uncommitted work.

Modern Restore Matrix

# Unstage file from staging area back to working tree (preserves edits)
git restore --staged <file>

# Discard uncommitted changes in working tree (DANGEROUS: wipes edits)
git restore <file>

# Discard all unstaged changes across entire working tree
git restore .

# Restore file to the version from 2 commits ago
git restore --source=HEAD~2 <file>
