Merge Conflict Resolution Cheat Sheet

Terminal commands and marker reference for untangling merge conflicts.

Conflict Resolution Playbook

# 1. Check which files are conflicting
git status

# 2. View conflicted sections across all files
git diff

# 3. Mark file as resolved after editing
git add <filename>

# 4. Finalize the merge commit
git commit

# Emergency Abort: cancel everything and restore prior state
git merge --abort
