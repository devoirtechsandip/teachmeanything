Revert vs Reset Quick Reference

Cheat sheet for undoing committed mistakes safely across public and private branches.

Undo Strategy Decision Matrix

Command History Mod Working Tree Target Environment
git revert <SHA> Appends new commit Clean Public/Shared Branches
git reset --soft HEAD~1 Rewinds pointer Preserved (Staged) Local Unpushed Only
git reset --mixed HEAD~1 Rewinds pointer Preserved (Unstaged) Local Unpushed Only
git reset --hard HEAD~1 Rewinds pointer Obliterated Local Unpushed Only
