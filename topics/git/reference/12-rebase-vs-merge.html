Rebase vs Merge Cheat Sheet

Comparing linear rebasing vs standard branch merging workflows.

Rebase Workflow Commands

# Rebase current feature branch onto updated main
git switch feat/user-profile
git rebase main

# If conflicts occur during rebase: resolve in editor, then
git add <file>
git rebase --continue

# Safely bail out of a rebase midway and restore prior state
git rebase --abort
