git stash Cheat Sheet

Commands for shelving and retrieving work in progress without committing.

Stash Command Reference

# Shelve all modified tracked files with a description
git stash push -m "description of work"

# Include untracked files in the stash (-u)
git stash -u

# List all stashed entries
git stash list

# Restore topmost stash and remove from list
git stash pop

# Restore specific stash without deleting it
git stash apply stash@{1}

# Discard topmost stash
git stash drop
