Quick Reference Card #14 ⚡ Cheat Sheet

git reflog & Disaster Recovery Cheat Sheet

Commands to rescue "lost" commits, undo bad rebases/resets, and resolve detached HEADs.

Recovery Playbook Commands

# View full chronological journal of all HEAD pointer movements
git reflog

# Resurrect a commit from reflog into a fresh branch
git switch -c rescue-branch <commit-hash>

# Fix Detached HEAD: attach a new named branch to current commit
git switch -c new-feature-name

# Undo a disastrous rebase using reflog pointer
git reset --hard HEAD@{1}
