Branch Management & Navigation Reference

Modern branch creation, switching, listing, and inspection cheat sheet.

Modern Branch Commands

# List local branches (* indicates current HEAD)
git branch

# List both local and remote tracking branches
git branch -a

# Create and switch to new branch (Modern Git 2.23+)
git switch -c feat/user-auth

# Switch to an existing branch
git switch main

# Delete a merged branch safely
git branch -d feat/user-auth

# Force delete an unmerged branch
git branch -D feat/abandoned-experiment
