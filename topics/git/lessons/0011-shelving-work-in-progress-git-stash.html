Shelving Work in Progress with git stash

Context-switch like a pro: learn how to safely shelve uncommitted messy experiments when an urgent hotfix strikes, without cluttering your commit history with ugly "WIP" commits.

1 The Mid-Sprint Emergency

You are in the middle of writing a 200-line feature. Suddenly, your manager reports a critical bug in production. You must switch to main right now to deploy a hotfix!

Git will block you from switching branches because your uncommitted files would clash. Making a half-finished commit named "asdf temp save" pollutes your team's git log.

📦 The Stash Solution

git stash takes your dirty Working Tree and Staging Area, saves them onto a private internal stack (the stash shelf), and resets your working tree to a completely clean state matching HEAD.

2 The Stash Lifecycle Commands

# 1. Save changes to stash with a meaningful label
$ git stash push -m "wip: navbar animation"

# 2. View all stored stashes
$ git stash list
stash@{0}: On feat/nav: wip: navbar animation

# 3. Restore your stashed changes and remove from shelf
$ git stash pop
