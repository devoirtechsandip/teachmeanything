Remotes Demystified: origin, clone & tracking branches

Bridge the gap between your local computer and GitHub/GitLab: understand what origin really means, how git clone works, and why remote tracking branches like origin/main are your local safety bookmarks.

1 What is "origin"? Just a Friendly Nickname!

Many beginners assume origin is a mystical Git keyword. In reality, origin is simply a shortcut alias for a URL.

Instead of typing git push https://github.com/company/super-cool-project.git main every time, Git lets you name that URL origin:

$ git remote add origin https://github.com/you/repo.git

2 Remote Tracking Branches: The Local Bookmark

When you connect to GitHub, Git creates Remote Tracking Branches on your machine, formatted like origin/main.

🔖 The Three Pointers of Distributed Git
  • main: Your local branch pointer that you move when committing.
  • origin/main: A read-only local bookmark recording where the server was during your last sync.
  • Remote main: The actual branch sitting on the remote GitHub server.
