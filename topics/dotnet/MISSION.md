# Mission: .NET & C# Mastery

## Why
Build deep proficiency in the modern .NET ecosystem and C# to design high-performance, robust, cross-platform backend services and applications.

## Success looks like
- Confidently use modern C# features (records, pattern matching, async/await, nullable reference types).
- Understand the .NET runtime (CLR), garbage collection, memory model, and performance characteristics.
- Architect ASP.NET Core applications using dependency injection, middleware pipelines, and minimal APIs.
- Build resilient data access layers with Entity Framework Core and raw ADO.NET / Dapper.
- Write robust unit and integration tests using xUnit, FluentAssertions, and Testcontainers.

## Constraints
- Focus on modern .NET (current LTS/STS versions: .NET 8 / .NET 9+).
- Practical code-first lessons with runnable examples and architectural trade-offs.

## Out of scope
- Legacy .NET Framework (4.x) WinForms or WCF systems, except when discussing migration trade-offs.
