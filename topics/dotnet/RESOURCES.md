# .NET Resources

## Knowledge

- [Book: _C# in Depth_ by Jon Skeet](https://csharpindepth.com/)
  Gold standard for deep understanding of C# language evolution, type system, and mechanics.
- [Book: _Pro .NET Memory Management_ by Konrad Kokosa](https://prodotnetmemory.com/)
  The definitive authority on CLR memory allocation, GC internals, and profiling.
- [Documentation: Microsoft .NET Architecture Guides](https://learn.microsoft.com/en-us/dotnet/architecture/)
  Official design patterns for microservices, cloud-native apps, and clean architecture in .NET.
- [Blog: Stephen Toub's Performance Improvements in .NET](https://devblogs.microsoft.com/dotnet/)
  Comprehensive yearly breakdown of runtime, library, and JIT optimizations.

## Wisdom (Communities)

- [r/csharp & r/dotnet](https://reddit.com/r/dotnet)
  Active developer communities for idiomatic discussions, library recommendations, and modern practices.
- [dotnet/runtime GitHub Discussions](https://github.com/dotnet/runtime)
  Direct engagement with the Microsoft runtime engineering team on RFCs and language proposals.
